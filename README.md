# JJ 기타

코드를 입력하면 어쿠스틱 기타 운지법(여러 폼)을 보여주고, 휴대폰 마이크로 줄을 맞출 수 있는 웹앱입니다.

## 기능
- 코드 검색: `C`, `Am7`, `F#m7b5`, `G/B`, `Cadd9`, `D6/9` 등 → 튜닝·카포 기준으로 운지 계산, 여러 폼 넘겨보기
- 코드 소리 듣기, 카포 위치별 운지 (카포 기준 모양 이름 표시)
- 마이크 튜너 (표준·드롭 D·반음 다운·오픈 튜닝), 줄별 기준음 재생
- 저장(로그인 없음, 이 브라우저에 저장): 즐겨찾기 코드, 내 튜닝 프리셋, 코드 진행/곡 메모

## 구조
- `public/` 정적 화면 (빌드 없음, 순수 ES 모듈)
- `test/` `npm test` (코드 엔진·튜너)

## 배포 (운영/개발 분리, GitHub Pages)
| 브랜치 | 환경 | 주소 |
|---|---|---|
| `dev` | 개발 | https://jeehjung.github.io/jj-guitar/dev/ |
| `main` | 운영 | https://jeehjung.github.io/jj-guitar/ |

각 브랜치에 push하면 GitHub Actions가 테스트 후 `gh-pages` 브랜치의 해당 경로에 배포합니다 (추가 Secrets 불필요).
모든 변경은 `dev`에만 커밋하고, 개발 환경 검증 후 `main`으로 머지합니다. 운영에 직접 커밋하지 않습니다.

로컬 미리보기: `npm run dev` → http://localhost:8000
